# SVT Mansion — 결과 수집 백엔드 (Google Apps Script)

`index.html`의 **이사하기** 버튼은 배치 결과를 Google Apps Script 웹앱으로 전송해 스프레드시트에 기록합니다. 이 폴더의 `Code.gs`는 그 웹앱의 **하드닝된** 서버 코드입니다.

## 왜 필요한가
기존 엔드포인트는 리포에 URL이 노출되어 있고 **입력 검증·스팸 방지가 전혀 없었습니다.** 누구나 아무 형태의 데이터를 무한정 POST할 수 있었죠. `Code.gs`는 서버측에서 스키마를 검증하고 봇/과대 요청을 걸러냅니다.

## 배포 방법
1. 결과를 기록할 **Google Sheet**를 엽니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script**.
3. 기존 코드를 지우고 `Code.gs` 내용을 붙여넣습니다.
4. 필요하면 상단 상수를 조정합니다.
   - `SHEET_NAME`: 기록할 탭 이름(없으면 자동 생성 + 헤더 추가).
   - `MAX_BODY_BYTES`: 본문 크기 상한(기본 10KB).
   - `EXPECT_TOKEN`: 값을 채우면 클라이언트가 같은 토큰을 보내야만 저장(선택).
   - `ALLOWED_RESIDENTS`: `index.html`의 `residents` 목록과 **동일하게** 유지.
5. **배포 → 새 배포 → 유형: 웹 앱**.
   - 실행 계정: **나**
   - 액세스 권한: **익명 사용자 포함 모든 사용자**
6. 생성된 **웹 앱 URL**을 `index.html`의 폼 action에 넣습니다:
   ```html
   <form id="gsheetForm" ... action="여기에_배포_URL/exec">
   ```
7. 배포 URL을 브라우저로 열어 `{"ok":true,"service":"svt-mansion","ready":true}`가 보이면 정상(헬스체크).

## 서버가 걸러내는 것
| 검사 | 거부 사유(응답 JSON `error`) |
|---|---|
| 허니팟 `hp` 채워짐(봇) | 저장 안 함 (`skipped:true`, 200) |
| 본문 10KB 초과 | `too_large` |
| 토큰 불일치(설정 시) | `bad_token` |
| JSON 파싱 실패 | `bad_json` |
| `results`가 배열 아님/15칸 아님 | `bad_results` |
| floor∉1..5 또는 unit∉1..3 | `bad_cell` |
| 허용 목록 밖 입주자 | `bad_resident` |
| 같은 호실 좌표 중복 | `dup_cell` |
| 같은 멤버 중복(공실 제외) | `dup_member` |

> **참고:** Apps Script 웹앱의 응답은 항상 HTTP 200입니다. 성공/실패는 **응답 JSON의 `ok` 필드**로 구분합니다(진짜 4xx 코드는 낼 수 없음).

## 시트 컬럼 매핑
`responses` 탭에 다음 순서로 한 행씩 추가됩니다:

```
recordedAt | submittedAt | userAgent | 501호 | 502호 | 503호 | 401호 ... 103호
```

(층은 5→1, 호는 1→3 순서 — 미리보기 화면과 동일)

## 보안 한계 (정직한 설명)
- 이 게임은 **정적 페이지**라, 클라이언트에 심는 토큰/검증은 소스에 노출되어 **우회 가능**합니다. 진짜 방어선은 위의 **서버측 스키마 검증**입니다.
- 검증을 통과하는 형식의 스팸(정상 형태의 대량 전송)까지 막으려면 서버측에 추가 방어가 필요합니다. 필요 시 다음을 권장합니다:
  - **일일 호출 상한**: `PropertiesService`에 날짜별 카운터를 두고 임계 초과 시 저장 중단.
  - **간이 레이트리밋**: 같은 IP는 Apps Script에서 직접 얻기 어려우므로, `CacheService`로 짧은 시간 내 중복 append 억제.
  - 민감 데이터가 아니므로 과도한 방어보다 **주기적 모니터링 + 시트 백업**으로 충분한 경우가 많습니다.
- 클라이언트측 완화책(허니팟 필드 + 5초 재전송 스로틀)은 `index.html`에 이미 적용되어 있습니다.

# 💎 SVT Mansion — 세븐틴이 한 아파트에 산다면?!

SEVENTEEN 멤버들을 5층 × 3호(총 15세대) 아파트에 직접 배치하고, 결과를 이미지로 저장·공유하는 팬용 웹 놀이입니다.

## 사용법
1. `index.html`을 브라우저로 엽니다 (별도 빌드/서버 불필요).
2. 각 호실 드롭다운에서 입주자를 고릅니다. 같은 멤버는 한 번만 배치할 수 있고, `공실`은 여러 번 배치 가능합니다.
   - `캐럿(나)`을 넣지 않으려면 공실 2칸으로 두면 됩니다.
   - **🎲 랜덤 배치**로 한 번에 무작위 배치할 수 있습니다.
3. **이사하기**를 누르면 아래에 입주 현황 미리보기가 생성됩니다.
4. **이미지로 저장하기** 또는 **📲 공유하기**로 결과를 저장/공유합니다.

## 기능
- 랜덤 배치 · 중복 방지 · 호실별/전체 초기화
- 배치 상태 자동 저장(localStorage) — 새로고침해도 유지
- 결과 미리보기 → PNG 저장 / Web Share API 원탭 공유(미지원 시 저장+문구 복사 폴백)
- 저장·공유 이미지에 해시태그 브랜딩 자동 포함

## 구조
- `index.html` — 단일 파일 (인라인 HTML/CSS/JS)
- `image/` — 멤버 프로필 이미지
- 결과 집계는 Google Apps Script 웹앱으로 전송(선택 기능)

## 의존성

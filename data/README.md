# 이벤트 데이터 편집 가이드 (관리자용)

게임의 "🎬 우리 아파트 이야기" 이벤트는 **`data/events.js` 파일 하나**로 관리됩니다.
개발 지식 없이도 이 파일만 고치면 이벤트를 추가·수정할 수 있어요. (코드 `index.html`은 건드릴 필요 없음)

## 어떻게 편집하나요?
1. GitHub에서 [`data/events.js`](events.js)를 엽니다 → 연필(✏️) 아이콘으로 편집.
2. 아래 규칙에 맞게 항목을 추가/수정합니다.
3. **Commit changes**를 누르면 반영됩니다. (GitHub Pages 새로고침)

> ⚠️ **문법 주의**: 각 항목은 `{ ... }`, 항목 사이는 쉼표 `,`. 문장 안에서 큰따옴표를 쓰려면 `\"`처럼 앞에 역슬래시. 괄호/쉼표가 하나라도 어긋나면 이벤트가 안 뜹니다. 편집 후 게임에서 이벤트가 안 보이면 문법을 다시 확인하세요.

## 이벤트 종류 (우선순위 높은 순)
모든 이벤트는 `text`(제목)와 `desc`(짧은 상황/대사)를 가집니다.

| 키 | 언제 뜨나 | 필드 |
|---|---|---|
| `combos` | 지정 멤버가 **모두 입주**(위치 무관, 2~13인) | `members: [..]`, `text`, `desc`, `legendary`(선택, true면 골드 강조) |
| `gose` | 입주 인원이 `config.goseMinPlaced` 이상일 때 하나 | `text`, `desc` |
| `pairs` | 두 멤버가 **옆집/위아래로 인접**(방향 무관) | `members: [A, B]`, `text`, `desc` |
| `directional` | **방향까지** 따짐 | 아래 참고 |
| `position` | **층 위치** | `floors: [층..]`(한 칸이라도 차면) 또는 `floorsAll: [층]`(그 층 만실), `text`, `desc` |
| `solo` | 멤버 옆에 이웃이 하나라도 있으면 | `{ "멤버명": [ {text, desc}, ... ] }` — 변형 여러 개 두면 배치마다 하나가 뽑힘 |

### 방향성(`directional`) 규칙
- 가로: `{ type: "horizontal", left: "왼쪽멤버", right: "오른쪽멤버", text, desc }`
  - `left`=호수가 작은 쪽(예 501), `right`=바로 옆 큰 쪽(예 502). 같은 층에서 붙어 있어야 발동.
- 세로: `{ type: "vertical", upper: "위층멤버", lower: "아래층멤버", text, desc }`
  - `upper`=위층, `lower`=바로 아래층 같은 라인(예 501 위, 401 아래).

## 설정(`config`)
- `maxEvents`: 카드에 표시할 최대 이벤트 수 (기본 5)
- `goseMinPlaced`: 고세 예능이 뜨는 최소 입주 인원 (기본 6)
- `caps`: 카테고리별 표시 상한 (한 종류가 카드를 도배하지 않도록)

## 예시 — 새 케미 추가
```js
// pairs 배열에 한 줄 추가
{ members: ["정한", "디노"], text: "정한·디노 옆집, 장난과 리액션의 콜라보 😆", desc: "\"형 또 장난쳐요!\" 복도가 시끌." },

// directional 배열에 세로 케미 추가
{ type: "vertical", upper: "민규", lower: "우지", text: "윗집 민규 발소리, 아랫집 우지 집중 방해 🔨🎧", desc: "\"형 조금만 살살…\"" },

// solo 에 멤버 변형 추가 (도겸)
"도겸": [ /* 기존들… */, { text: "도겸, 복도에서 고음 연습 중 🎤", desc: "유리창이 떨린다는 소문." } ]
```

## 콘텐츠 톤 (권장)
공개된 팬덤 이미지(유닛/서브유닛/듀엣곡/자체예능/멤버 간 케미) 기반의 **밝고 긍정적인** 문구만. 부정적·사생활 관련 내용은 넣지 않습니다. 설계·자료 출처는 [`docs/EVENT_ENGINE.md`](../docs/EVENT_ENGINE.md) 참고.

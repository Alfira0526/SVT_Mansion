# 이벤트 엔진 설계 (Event Engine)

결과 카드의 "🎬 우리 아파트 이야기"를 생성하는 엔진. 배치(위치·이웃·조합·방향)를 읽어 **밝고 긍정적인 팬덤 서사 이벤트**를 만든다. 로직은 `index.html`의 `generateEvents()`(순수·결정적 함수), **데이터는 외부 파일 [`data/events.js`](../data/events.js)** 에 분리 — 관리자가 GitHub에서 직접 편집 가능(편집 가이드 [`data/README.md`](../data/README.md)).

## 데이터 분리 구조 (관리자 편집)
- `data/events.js` 가 `window.SVT_EVENT_DATA`(traits/combos/pairs/directional/position/solo/gose/config)를 정의.
- `index.html`은 이 전역을 참조. `<script src="data/events.js">`(전역 할당 방식) → **`file://`·GitHub Pages 모두 동작**(JSON+fetch는 file://에서 CORS로 막혀 사용 안 함).
- 데이터 파일 미로드 시에도 게임은 정상 동작하고 이벤트 섹션만 생략(안전 degrade).

## 이벤트 카테고리 (티어 순)
1. **레전드**(tier 0): `combos` 중 `legendary:true`. 골드 강조, 상한 무시.
2. **조합**(1): `combos` — 지정 멤버 전원 배치(2~13인). 유닛·부석순·96즈·백구·리더라인 등.
3. **고세 예능**(2): 입주 인원 `config.goseMinPlaced` 이상이면 하나.
4. **옆집 케미**(3): `pairs` — 두 멤버 인접(방향 무관).
5. **방향성 케미**(3): `directional` — horizontal(left↔right 같은 층)·vertical(upper↔lower 같은 라인). "왼쪽/오른쪽·위층/아래층" 구도.
6. **위치**(4): `position` — floors/floorsAll.
7. **개인**(5): `solo` — 이웃 있으면 멤버별 변형 중 시드로 하나.

카테고리별 상한(`config.caps`)으로 다양성 확보, 최대 `config.maxEvents`개.

## 페르소나 회의 결론 (설계 반영)
| 페르소나 | 요구 | 엔진 반영 |
|---|---|---|
| 트위터 고인물 | 짤/인용각, 리롤마다 새 이야기, '플렉스'용 레전드 | 배치별 결정적 시드(같은 배치=같은 이야기, 다른 배치=다른 이야기) + **레전드 이벤트**(골드 강조) |
| 시나리오 작가 | 톤 일관성, 카테고리 다양성, 반복 방지 | 카테고리(유닛/케미/위치/개인/고세) + **카테고리별 상한**으로 한 종류 도배 방지 |
| 서비스 기획자 | 명확한 규칙·우선순위·상한, 신뢰성 | **티어 우선순위**(레전드>유닛>고세>케미>위치>개인), 최대 5개 |
| 디자이너 | 카드에 들어갈 분량, 레전드 시각 구분 | 5줄 상한, 레전드는 `.legend`(골드) 스타일, 상황문구는 축소·들여쓰기 |
| 서버 개발자 | 순수/결정적/테스트가능, 데이터·로직 분리, 조합폭발 방지 | `generateEvents(results)` 순수함수, 규칙은 데이터 테이블, mulberry32 시드 PRNG(Math.random 미사용) |
| 아이돌 엔터사 기획자 | 브랜드 세이프, 공개 사실 기반, 이미지 보호 | 공개 유닛/서브유닛/듀엣곡/자체예능 사실만 사용, 부정·사생활 언급 배제, 애정 어린 톤 |
| **소설작가**(추가) | 이벤트마다 "한 컷 장면", 멤버 성향을 캐릭터 보이스로 | 이벤트 스키마에 **`desc`(상황 묘사/대사 1줄)** 추가, 멤버 성향표 기반 서술 |
| **예능작가**(추가) | 자막·리액션 감성의 짧고 웃긴 대사, 고세 상황극 | `desc`에 따옴표 대사·예능 자막 톤, 고세 포맷 상황 확장 |

## 이벤트 규모 & 스키마
- **총 118개** (개인 53 · 옆집케미 28 · 방향성케미 10 · 조합 13 · 위치 4 · 고세 10).
- 스키마: `{ text, desc }` — `text`는 훅(제목), `desc`는 **짧은 상황/대사**. 카드엔 상위 5개를 `제목 + 상황` 2줄로 표시.
- 개인 이벤트는 멤버당 여러 변형을 두고 시드로 하나 선택(리롤 다양성).

## 선택 로직
- 발동한 이벤트를 모아 시드 셔플 → 티어 오름차순 안정 정렬 → 카테고리 상한(`config.caps`) 적용 → 최대 `config.maxEvents`개.
- 시드는 배치(칸-멤버) 해시 기반 → **같은 배치는 항상 같은 이야기**(신뢰성), 배치가 바뀌면 이야기도 바뀜(리롤 재미).

## 콘텐츠 자료 출처 (수집)
공개 자료로 유닛 구성·서브유닛·믹스유닛 듀엣·자체예능 포맷·멤버 간 케미를 확인해 문구에 반영:
- **유닛 구성 / 부석순 / 믹스유닛**: 나무위키·위키백과·Weverse Magazine, 언론 — 힙합팀(에스쿱스·원우·민규·버논), 보컬팀(정한·조슈아·우지·도겸·승관), 퍼포먼스팀(준·호시·디에잇·디노), 부석순(부승관·이석민·권순영).
- **믹스유닛 듀엣곡**: 호시×우지 '동갑내기', 정한×원우 '어젯밤', 에스쿱스×민규 'Pretty Woman', 도겸×승관 'Blue'.
- **[나무위키 「세븐틴/멤버 간 케미」](https://namu.wiki/w/세븐틴/멤버%20간%20케미)** — 팬덤 공인 케미명 반영:
  - **뱅쇼** = 조슈아·승관(오렌지·귤, '뱅쇼타임')
  - **느모** = 원우·버논(느린 애·모르는 애)
  - **진짜꽃즈/캐치볼즈** = 우지·도겸(화분 ASMR)
  - **도겸·민규 앙숙케미**(아웅다웅), **호시·원우**(겁 많은 근육콤비)
  - **96즈(마불지즈)** = 준·호시·원우·우지(96년생 원년멤버), **백구** = 에스쿱스·정한·민규(민규 놀리기)
- **고잉세븐틴 포맷**: TTT(MT/썰), 돈치기/돈't Lie, 방탈출, 어몽어스 현실판, 노래방.
- **멤버 롤/별명**: 리더(에스쿱스), 천재작곡가(우지), 텐션·호랑이(호시), 예능·리액션(승관), deadpan·게임(원우), 살림·사고(민규) 등.

> 나무위키는 봇 차단(403)으로 직접 크롤 불가 → **웹 검색 스니펫**으로 케미명·설명 확인. 유튜브 Data API는 일일 쿼터 초과로 미사용.
> 확인한 나무위키 문서: 「세븐틴」(본 문서), 「세븐틴/멤버 간 케미」, 유닛·부석순·고잉세븐틴 관련 섹션.

## 확장 방법
